# JUONG Glass Theme

Apple tvOS inspired spatial glassmorphism theme for JUONG TV on Xiaomi TV L55MA-EA.

## Highlights
- Deep Charcoal Backdrop (`#070A0F`)
- Translucent Frosted Glass Dock with 28dp smooth corners
- Focus Elevation & Dynamic Horizon Glow
- Apple tvOS Cinematic Top Shelf with category tags
- Pinned applications optimized for streaming, web browsing (TV Bro), and media playback
- 11 high-definition official 16:9 wallpapers with captions and 30-minute auto-rotation
- 100% lightweight simulation: zero GPU shader overhead for smooth 60fps on Amlogic 1.5GB RAM
