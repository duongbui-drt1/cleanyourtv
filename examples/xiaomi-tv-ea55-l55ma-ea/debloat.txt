# Xiaomi TV EA55 (Mã hiệu L55MA-EA / MiTV-ASTP0 / AETP0 - Mulan)
# Hệ điều hành: MIUI for TV / Android 9 / HyperOS (Firmware nội địa Trung Quốc)
# Cấu hình: Chip Amlogic, 1.5GB / 2GB RAM, màn hình 55 inch 4K
#
# QUY TẮC AN TOÀN CHO L55MA-EA:
# 1. KHÔNG disable com.mitv.tvhome nếu chưa cài đặt HomeKeyService hoặc Launcher thay thế ổn định.
# 2. KHÔNG disable mitv.service (dịch vụ âm thanh, hình ảnh phần cứng TvService; tắt sẽ gây treo Settings).
# 3. KHÔNG disable com.android.bluetooth (remote Bluetooth giọng nói).
#
# Lệnh chạy tự động:
# Windows (PowerShell): .\tweak-xiaomi-l55ma-ea.ps1 -Ip <IP_CỦA_TV>
# Windows (CMD):       tweak-xiaomi-l55ma-ea.bat <IP_CỦA_TV>
# Linux/macOS:         TV_HOST=<IP_CỦA_TV> tools/disable.sh examples/xiaomi-tv-ea55-l55ma-ea/debloat.txt
